# For My Devi ♡

A mobile-first romantic scrapbook website — a little world of ours.

## Run locally
Open `index.html` in a browser. No build step or backend is required.

## Features
- Her World mood check-in
- A softer place for reflection and promises
- Together Canvas with undo, redo, eraser and PNG export
- Love notes and little memories saved in this browser
- Our Someday dream cards

## Data & privacy
This first version stores notes, memories and check-ins in the browser's localStorage on the device being used. It does not sync between devices. A backend can be added later after the frontend is tested.

## Deploy
Import this repository into Vercel, or enable GitHub Pages from Settings → Pages and deploy from the `main` branch root.
